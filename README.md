## Overview

`SkillForge` transforms personal development into an engaging, structured progression system. It combines habit tracking, daily technical quests, and automated milestone analytics to help engineers build disciplined work habits and track long-term skill acquisition.

[**Explore Live Deployment ↗**](https://skill-forge-gamma.vercel.app)

### Core Capabilities
* **Quest & Milestone Tracking:** Break complex engineering goals into discrete, quantifiable daily tasks.
* **Habit Leveling Engine:** Automated experience calculation algorithms based on completion consistency and difficulty tiers.
* **Full-Stack Architecture:** TypeScript throughout both client and server layers for end-to-end type safety.
* **Production Deployed:** Deployed and actively accessible on Vercel with responsive mobile and desktop support.

## Quickstart

### Prerequisites
* Node.js 18+
* npm or yarn

### Installation
```bash
git clone https://github.com/Divyanshkumar62/Skill_Forge.git
cd Skill_Forge

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173` to explore the application locally.
